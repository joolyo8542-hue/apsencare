📊 성과 분석

병원 수납액 성장률과 환자 유지율을 분석합니다

📂 데이터 추출 경로 (덴트웹)
경영/통계 → 의사별 수납액 통계 → 해당 의사 선택 → 📥 엑셀 저장 → 💾 월간 자료 저장
💡 예시: 구강관리팀 → 가상의사 설정 후 월별로 엑셀 저장
⚠️ 저장한 파일을 아래 안내에 따라 반드시 정제(열 삭제)한 후 업로드해주세요
✅ 업로드 전 엑셀 열 정제 안내
덴트웹에서 추출한 파일에서 아래 5개 열만 남기고 나머지 열은 모두 삭제해주세요.
유지할 열 용도
진료일 내원건수 집계 (분석 후 즉시 삭제)
차트번호 내원건수 집계 (분석 후 즉시 삭제)
수납구분 보험본인부담 / 비급여 분류
진료금액 금액 합산
총수납액 미수/환불 차이 분석
🗑 위 5개 열 외 나머지는 모두 삭제 (순번, 수납일, 보험구분, 최초내원, 고객구분2 등)
📌 파일명은 기간이 포함된 원본 파일명을 그대로 유지해주세요 (날짜 자동 인식)
🔒 업로드 전 보안 & 개인정보 필수 확인사항
✂️ 열 정제 확인
📋 개인정보 미포함 확인
🏥 의료기관 보안 확인
✅ 정제 후 허용 데이터: 진료일·차트번호(내원건수 집계) + 금액 관련 열 (건별: 수납구분·진료금액·총수납액 / 금액열: 본인부담금·공단부담금·비급여·총진료비)
🛡️ 안전 보장: 모든 분석은 브라우저(클라이언트) 내에서 처리되며, 파일이 서버에 업로드되거나 저장되지 않습니다
⚖️ 법적 근거: 개인정보보호법 제17조, 의료법 제21조에 의거 환자 식별정보는 반드시 제거 후 업로드해야 합니다
🏥 의료기관 유형 선택
💡 공단부담금 = 본인부담금 ÷ 0.4 × 0.6 으로 추산됩니다
📊 정제된 월별 수납통계 Excel 파일을 업로드하세요 (여러 파일 동시 선택 가능)

• 파일명은 원본 그대로 유지: 2024-01-01_2024-01-31수납통계.xlsx (기간 자동 인식)
• 지원 양식 ① 건별: 진료일, 차트번호, 수납구분, 진료금액, 총수납액
• 지원 양식 ② 금액열: 진료일, 차트번호, 본인부담금, 공단부담금, 비급여, 총진료비
• 양식은 자동 인식되며, 제목·합계 행이 있어도 괜찮습니다
• 공단부담금은 파일에 값이 있으면 실제값을, 없으면 위에서 선택한 의료기관 유형 비율로 추산합니다
• 최소 2개월 이상의 파일을 업로드해야 추이 분석이 가능합니다

📊 월별 수납 구성 추이

보험 수납(본인부담) + 비급여 수납

📊 항목별 금액 비교

본인부담금 · 공단부담금 · 비급여

📊 총진료비 추이

총진료비 = (본인부담 + 공단부담) + 비급여

📋 월별 상세 데이터

월 본인부담금 공단부담금 (추정) 비급여 총진료비 내원건수 수납합계 객단가 비급여비율
📅 비교할 연도 선택
동일 월(1~12월)을 X축으로 선택한 연도들을 겹쳐 비교합니다

💰 수납합계 비교

본인부담 + 비급여

🏥 내원건수 비교

차트번호+진료일 기준

💎 객단가 비교

총진료비 ÷ 내원건수

🧡 비급여비율 비교

비급여 ÷ 총진료비 × 100 · 목표 30%

📋 연도별 월간 비교표
